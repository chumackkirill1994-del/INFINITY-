## ЧАСТЬ 1 — Google Apps Script (настраивается один раз)

### Шаг 1 — Создайте Google Таблицу

1. Откройте [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу, назовите её `INFINITY Записи`
3. На первом листе создайте заголовки в строке 1:
   - Ячейка A1: `Дата`
   - Ячейка B1: `Имя`
   - Ячейка C1: `Телефон`
   - Ячейка D1: `Направление`
4. Переименуйте лист: двойной клик на вкладке снизу → `Записи`

### Шаг 2 — Создайте Apps Script

1. В таблице: **Расширения → Apps Script**
2. Откроется редактор. Удалите весь код который там есть
3. Скопируйте весь код из файла `code.gs` и вставьте
4. Нажмите 💾 (сохранить), назовите проект `INFINITY`

### Шаг 3 — Опубликуйте скрипт

1. Нажмите **Развернуть → Новое развертывание**
2. Тип: выберите **Веб-приложение**
3. Настройки:
   - Описание: `infinity-v1`
   - Выполнять от имени: **Я** (ваш аккаунт)
   - Доступ: **Все** (важно!)
4. Нажмите **Развернуть**
5. При первом запуске — дайте разрешения (нажмите «Дополнительно» → «Перейти»)
6. **Скопируйте URL** — он выглядит так:
   ```
   https://script.google.com/macros/s/AKfycbx.../exec
   ```
   Это ваш `APPS_SCRIPT_URL`

### Шаг 4 — Вставьте URL в index.html

Откройте `index.html`, найдите строку (~строка 680):
```javascript
const APPS_SCRIPT_URL = 'ВСТАВЬТЕ_ВАШ_URL_СЮДА';
```
Замените на:
```javascript
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/ВАШ_КОД/exec';
```

### Шаг 5 — Вставьте URL в admin.html

1. Откройте `admin.html` в браузере (уже загруженный на GitHub Pages)
2. Перейдите в раздел **Настройки**
3. Вставьте Apps Script URL
4. Также вставьте ссылку на вашу Google Таблицу

## ЧАСТЬ 2 — GitHub Pages (размещение сайта)

### Шаг 1 — Создайте репозиторий

1. Откройте [github.com](https://github.com) → войдите в аккаунт
2. Нажмите **New repository** (зелёная кнопка)
3. Название: `infinity-site` (или любое другое)
4. Тип: **Public**
5. Нажмите **Create repository**

### Шаг 2 — Загрузите файлы

1. На странице репозитория нажмите **uploading an existing file**
2. Перетащите все файлы:
   - `index.html`
   - `admin.html`
   - `hal_1.webp`
   - `hal_2.webp`
   - `hal_3.webp`
   - `hal_4.webp`
   - `razdevalka.webp`
3. Нажмите **Commit changes**

### Шаг 3 — Включите GitHub Pages

1. В репозитории: **Settings → Pages** (в левом меню)
2. Source: **Deploy from a branch**
3. Branch: `main` → папка `/ (root)`
4. Нажмите **Save**
5. Через 1-2 минуты появится ссылка вида:
   ```
   https://ВАШ_НИК.github.io/infinity-site/
   ```

### Шаг 4 — Проверьте сайт

- Главная: `https://ВАШ_НИК.github.io/infinity-site/`
- Админка: `https://ВАШ_НИК.github.io/infinity-site/admin.html`

## ЧАСТЬ 3 — Как обновлять расписание

### Вариант А — Через admin.html (легко)

1. Откройте `https://ВАШ_НИК.github.io/infinity-site/admin.html`
2. Войдите (пароль по умолчанию: `infinity2024`)
3. Перейдите на вкладку **«Расписание»**
4. Отредактируйте нужные ячейки
   - Формат: `Название занятия | Имя тренера`
   - Пример: `Йога | Светлана`
5. Нажмите **«Экспорт кода для index.html»**
6. Скопируйте сгенерированный код
7. Откройте `index.html` в текстовом редакторе
8. Найдите строку `const scheduleData = [` (примерно строка 587)
9. Замените весь блок `scheduleData` скопированным кодом
10. Загрузите обновлённый `index.html` на GitHub

### Вариант Б — Прямо в index.html (для технарей)

Найдите в `index.html`:
```javascript
const scheduleData = [
    ['09:00', ...],
    ...
];
```

Каждая строка = одно время. Формат ячейки:
```javascript
'НазваниеЗанятия<span>ИмяТренера</span>'
```

Пустая ячейка = `''`

Пример — добавить Пилон в понедельник в 17:00:
```javascript
['17:00', 'Pole Sport<span>Надежда</span>', '', '', '', '', 'Zumba<span>Ксения</span>', ''],
```

## ЧАСТЬ 4 — Как смотреть заявки

1. Откройте `admin.html`
2. Войдите с паролем
3. На вкладке **«Заявки»** нажмите **«Обновить»**
4. Все заявки загрузятся из Google Таблицы

Или просто откройте Google Таблицу напрямую.

## ЧАСТЬ 5 — Безопасность

### Смените пароль от admin.html
1. Войдите в admin.html
2. Раздел «Настройки» → «Пароль»
3. Введите новый пароль и сохраните

### Email-уведомления
Чтобы получать письмо при каждой новой заявке:
1. Откройте Apps Script
2. Найдите закомментированный блок `sendNotification`
3. Раскомментируйте его (уберите `/*` и `*/`)
4. Вставьте свой email
5. Переопубликуйте скрипт (Развернуть → Управление → Изменить)

## Частые вопросы

**Форма не отправляет заявки?**
→ Убедитесь что в `index.html` правильно прописан `APPS_SCRIPT_URL`
→ Убедитесь что скрипт опубликован с доступом «Все»

**admin.html показывает ошибку загрузки заявок?**
→ Проверьте URL в разделе «Настройки»
→ Откройте URL напрямую в браузере — должен вернуть JSON

**Как обновить фото в галерее?**
→ Замените файлы `hal_1.webp`...`razdevalka.webp` на свои с теми же именами
→ Загрузите на GitHub (при загрузке файла с таким же именем он заменится)

**Как изменить телефон или адрес?**
→ В `index.html` ищите `+7 (969) 732-48-41` и `ул. Пушкинская, 34Б`
